- The FFmpeg executable supplied by `imageio-ffmpeg` is distributed as a separate executable and is licensed under LGPL 2.1 or later in the standard `imageio-ffmpeg` builds. - Audio output uses `sounddevice` and its PortAudio backend. Their upstream license notices apply to packaged binaries; consult package metadata for the version used in a particular build.
- Optional instrument analysis uses **ONNX Runtime** under the MIT License to run the **YAMNet ONNX** model locally. The model is distributed under Apache License 2.0 and is downloaded on first use from [audiomagic/yamnet-onnx](https://huggingface.co/audiomagic/yamnet-onnx). The **AudioSet class map** is licensed under CC BY 4.0; attribution: Gemmeke et al., “Audio Set: An ontology and human-labeled dataset for audio events,” IEEE ICASSP 2017, [AudioSet](https://research.google.com/audioset/).
- The browser editor can optionally load **ONNX Runtime Web** and **Transformers.js** from jsDelivr/esm.sh, plus the [Musical-Instrument-Classification-ONNX](https://huggingface.co/onnx-community/Musical-Instrument-Classification-ONNX) model (MIT). The editor links to each model and displays when a model is used; their files are downloaded by the browser on demand, not bundled with the desktop installers.
- Optional browser audio separation uses the `@audio/neural-separate` SCNet module from esm.sh. It runs in the browser and downloads its model on demand; consult the upstream package metadata for its current license and model terms.
- The optional desktop transcription engine is based on [Damien Ronssin's `muscriptor.cpp`](https://github.com/DamRsn/muscriptor.cpp), pinned to commit `8589219cc3b584bce970f95aec2ec4a04e53b280`. The port and original MuScriptor code are MIT licensed; their copyright and permission notices must be included with distributed builds. The port also includes PFFFT under its separate BSD-style notice in the upstream source and ggml; see the corresponding upstream notices. The model weights are separate files and are **not** bundled with the app. The official GGUF weights are downloaded on explicit user action from [DamRsn/muscriptor-gguf](https://huggingface.co/DamRsn/muscriptor-gguf) and are licensed CC BY-NC 4.0 by the MuScriptor authors. The app verifies the published SHA-256 for each selected size. The user confirmed that all use of these weights in this pilot will be non-commercial; the license permits non-commercial use only. Check licensing again before expanding the model use beyond this pilot.
- The optional AcoustID lookup is a third-party service, not included in the app. It sends the user-provided client key and an audio fingerprint only when the user runs track recognition; see [AcoustID](https://acoustid.org/).
